# Zerodisk-router
Turning an old HP Pavilion dv4 with 3GB DDR2 RAM and no hard drive into a lightweight router using a persistent USB drive.

Zero Disk Router is a DIY project that repurposes an old HP Pavilion dv4 laptop with no internal hard drive and only 3GB of DDR2 RAM into a lightweight network router.Instead of installing an operating system onto a hard disk, the system runs from a USB pendrive with persistent storage, allowing the laptop to operate completely without an internal disk.

Hardware:
-HP Pavilion dv4
-3GB DDR2 RAM
-No internal hard disk
-USB pendrive with persistent storage
-Built-in/network adapters as available

Project Goals:
-Run a router OS without an internal hard drive
-Keep the setup lightweight enough for 3GB RAM
-Use persistent USB storage for configuration and packages
-Reuse old hardware instead of throwing it away
-Document the entire setup so others can reproduce it
